# KosMore 1.2.0

November 6, 2026

This release adds family reminders and available-card counts while proposing trades, family-tier impact badges on the Fusion page, and a Fusion navigation shortcut. Settings gain a purple starfield theme and feature switches that save immediately.

## Trade reminders

- See the selected player's preferred card families saved through KosMore on Social or their profile.
- On **Their card**, family badges appear below the “Only the cards…” text, above **Possible Interest** and the search bar. On **Your card**, the families and breakdown appear below the trade rule and above search. Other trade steps show the families below the step numbers.
- **Possible Interest** counts your available copies matching any of the player's saved families, grouped by rarity: Common, Uncommon, Rare, Epic, Legendary, and Mythic.
- Counts exclude locked copies and copies currently for sale. Available Standard, Shiny, and Full art copies are included. Overlapping families count each copy once, and results cover the complete matching collection rather than the visible search page.
- Zero-count rarities and an empty breakdown stay hidden. Filters on their cards do not change your counts.
- A spinner beside **Possible Interest** shows when calculation is in progress. Reserved space keeps the search controls from shifting as the counts arrive.
- The new **Settings → Trade reminders** group sits directly after **Profile reminders**. Family badges and interest counts can be enabled separately. **Use rarity symbols** is a nested switch under the counts option; turn it off to show rarity names instead.
- Trade reminders work independently of hover tooltips. Direct trade links read the player from the route, and fallback avatar initials no longer become part of the player's name.

## Fusion family impact

- Fusion grid cards gain a badge on the bottom left of the card art: **✓ Safe** when fusing the card keeps every family tier, or **⚠ Loses Asteroids I** when a family would drop from the displayed tier. A `+1` indicates another affected family.
- Impact considers all of the card's tier-counting families, the copies you keep, and the cards already selected in the tray. Non-economic family memberships are excluded.
- Calculations follow complete fusion batches in pick order. A chosen card still waiting for its batch has a dashed badge outline.
- Family counts refresh after fusion-related grid reloads, when the tray empties, and when returning to the tab. Reads share KosMore's cache and request scheduler with card overlays; card-family reads are limited to cards near the viewport and in the tray.
- Badges do not block card selection or submit fusions. Control them with **Settings → Card overlays → Show family impact on the Fusion page**. They continue working when hover tooltips are disabled.

## Settings appearance and controls

- Settings now use a star background, purple gradients, and darker translucent outer panels, with distinct nested option boxes.
- Every feature group's top-right switch saves and applies immediately, including when turning a feature off. Other options retain their group's **Save** and **Cancel** controls.
- Disabled groups disable their options and Save/Cancel buttons while preserving saved preferences. Unsaved option drafts remain available when you re-enable the group on the same settings page.
- Feature switches preserve unrelated option drafts, synchronize between settings tabs, and restore the previous switch state if saving fails.
- **Sales Overlay** uses checkboxes for price visibility, with nested switches for click-to-fill behavior. **Close Unpinned Tooltips When Added to Album** remains a checkbox, with **Also Close Pinned Tooltips** as a nested switch.

## Navigation hotkeys

- Added **Fusion**, bringing the list to 15 destinations. Assign your own key in **Settings → Navigation hotkeys**; no default shortcut is imposed.
- Shortened the market destination labels to **Market**, **My Auctions**, **My Activity**, and **Alerts**.
- Existing shortcut bindings and destinations are preserved.

## Documentation and compatibility

- Reorganized the README with a feature list first, installation and update instructions next, then detailed explanations of every settings group. The release's plain-text README matches the Markdown documentation.
- Corrected merge artifacts in the README and API client, and rebuilt the bundled extension files with the merged features.
- Existing saved preferences and format-version-1 backups remain supported. Missing new trade and Fusion preferences receive defaults without resetting existing choices. These preferences are included in settings backups.
- Permissions remain **storage** and access to **https://kosmora.io/**. No additional permissions are required.

## Install or update

Download **KosMore-1.2.0.zip**. The packaged extension requires no Node.js, pnpm, or source checkout. It targets Chromium-based browsers, with Chrome 120 as the declared minimum version.

**New installation**

1. Extract the ZIP to a permanent folder, such as `Documents\KosMore`.
2. Open your browser's Extensions page: `chrome://extensions`, `edge://extensions`, or `vivaldi://extensions`.
3. Enable **Developer mode**, choose **Load unpacked**, and select the extracted folder containing `manifest.json`.
4. Refresh existing Kosmora tabs and open KosMore from the Extensions menu to configure it.

**Updating an existing installation**

1. Optionally export a backup through **KosMore settings → Backup & restore**.
2. Replace the files in your existing extension folder with the extracted release files.
3. Click **Reload** on KosMore in the browser's Extensions page, keeping the existing installation to preserve settings and notes.
4. Refresh Kosmora tabs and reopen settings. Unpacked installations require manual updates.

For source installations, run `pnpm install` and `pnpm build`, then reload the extension from the rebuilt `dist` folder. Pulling source alone does not rebuild the extension.

## Verification and limits

- Type checking, all **218 unit tests**, the production build, and all **118 browser tests** passed. Browser tests cover trade routes and counts, stable loading layout, Fusion impact, settings behavior, navigation, backups, and the existing tooltip features.
- The actual release ZIP was checked in an isolated browser profile for version 1.2.0, settings compatibility, the new trade and Fusion options, and all 15 navigation destinations. Packaging verifies archive contents and omits source maps.
- Trade counts and Fusion badges depend on current Kosmora data and may need to reload after collection changes. These helpers do not submit trades, sales, or fusions for you. Automated fixture checks do not establish successful live transactions.
- Kosmora page or API changes may require an extension update.

When reporting a problem, include **KosMore 1.2.0**, the Kosmora page, reproduction steps, and expected versus actual behavior.
