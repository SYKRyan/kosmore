# KosMore 2.0.60

### First installation

1. Download `KosMore-2.0.60.zip`. Extract it into a folder you will keep, such as `Documents\KosMore`. Open that folder and find `manifest.json`. This is the folder you will select in step 3.
2. Open the Extensions page in the browser you use for Kosmora. In Chrome, enter `chrome://extensions` in the address bar. In Edge, enter `edge://extensions`. In Vivaldi, enter `vivaldi://extensions`.
3. Turn on **Developer mode**. Select **Load unpacked**, choose the folder containing `manifest.json`, and confirm. The Extensions page should now list **KosMore 2.0.60**. Keep that folder in place.
4. Open Kosmora in the same browser profile and sign in to the player you want to link. Refresh any Kosmora tabs that were already open.
5. Open the browser’s **Extensions** menu and select **KosMore** to open Settings. Select the red **Connect Account** button at the top.
6. Leave the masked **KosMore Services API base URL** filled in. If you received a tester invite code, enter it. Select **Connect**, allow access to the Services host if prompted, and approve KosMore in the Kosmora sign-in window.
7. Return to KosMore Settings. A green **Connected to** badge showing your player handle confirms setup.

If the sign-in window does not open, select **Copy Link** in **Connected Account**. Paste the link into a new tab in the same browser profile, approve KosMore, then return to Settings. If needed, copy the **Sign-in link** field manually.

On **Vivaldi for Android**, extract the ZIP with your Files app. In Vivaldi, enable **Desktop Site**, then open **Extensions → Manage Extensions**. Continue at step 3 and tap **Select Folder** when prompted.

### Update an existing installation

You can update directly from 2.0.51. These steps also apply to other unpacked releases from 2.0.1 onward.

1. Open the browser profile where KosMore is already installed. For an optional backup, open **KosMore Settings → Backup & Restore → Export backup** and save the file.
2. Download `KosMore-2.0.60.zip` and extract it. Open the extracted folder that contains `manifest.json`.
3. Copy the **contents** of that folder into the folder your browser already uses for KosMore. Choose **Replace** or **Overwrite** when prompted. The new `manifest.json` should replace the old one at the same location.
4. On the browser’s Extensions page, find the existing **KosMore** entry and select **Reload** (the circular arrow). Check that the version now reads **2.0.60**.
5. Refresh your open Kosmora tabs and reopen KosMore Settings. If the green badge shows your handle, you’re done. If you see **Connect Account**, follow steps 5–7 under **First installation**. Your saved settings and notes carry over with an in-place update.

## Changes since 2.0.51

### Pack openings

- **Open 10 at once** appears beside **Open the Next Pack** on single-pack and batch summaries when **Pack Openings** is enabled, your player has the batch-opening talent, and at least ten more packs are ready. Each click opens one batch. The remaining-pack count now sits below the buttons and can be hidden independently.
- The button rechecks your account and inventory before opening. It shows the confirmed cards in the next recap and keeps packs held for individual opening out of the next batch. If all ten are held, the first held pack opens individually. If KosMore cannot confirm the result, it asks you to check your pack history before trying again.
- A star spins on the button while the batch is being prepared. It stays still with reduced motion enabled.
- To assign the new shortcut, open **Settings → Hotkeys → Pack Opening**, enable pack opening hotkeys, record a key for **Open 10 at once**, and select **Save**. It starts unassigned and works on both the Packs page and eligible summaries.

### Market tooltips

- **Sell Many:** Hover anywhere in a listing row to inspect its card. In overlay-button mode, the button sits at the lower-left of the thumbnail. You can keep editing the price or choosing a copy while the tooltip is open.
- **Sell Single:** A pinned tooltip follows the card on the sell form as soon as it appears, including when you navigate from another card or the form loads after the page.

### Account connection and Settings

- The hosted Services URL comes prefilled in a masked, editable field. New users can select **Connect** immediately. On upgrade, an empty field picks up the default, a valid login at the same address carries over, and a saved self-hosted URL stays in place.
- The default follows future releases. To use a different service, enter its URL in **Connected Account**. To resume following the default, clear the field and click outside it. If the service address changes, select **Connect** to authorize the new address. Fork maintainers can set `defaultBaseUrl` in `public/services-config.json` before building.
- When you need to link or regain access, the **Connect Account** header button, **Connected Account** sidebar link, and border around that settings group pulse red. Selecting the badge or sidebar link takes you to the connection controls. The highlights clear when access is restored and stay steady with reduced motion enabled.
- The Settings wordmark now shows **Kos** in white and **More** in teal.
