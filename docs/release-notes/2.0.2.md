# KosMore 2.0.2

In **Settings → Connected Account**, choose **Copy Link** to sign in through a regular tab. Paste the link into another tab in the same browser profile and approve KosMore. The tab confirms the linked account and Settings updates automatically. If the clipboard is unavailable, touch and hold the sign-in link field to copy it manually.

If **Connect** cannot open a sign-in window on Vivaldi Android, choose **Copy Link** to continue the same sign-in while the link is valid. Sign-in links expire after ten minutes.

**Updating from 2.0.0:** Export a backup before replacing the old installation. Extract 2.0.2 to a separate folder, disable the old installation, and load the new folder unpacked. Import the backup and reconnect the same Kosmora account under **Connected Account**. This migrates settings and notes to the stable extension ID introduced in 2.0.1.

**Updating from 2.0.1:** Replace the files in your existing extension folder, reload KosMore on the Extensions page, and refresh your Kosmora tabs.
