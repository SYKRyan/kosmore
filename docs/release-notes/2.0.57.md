# KosMore 2.0.57

The Services URL is now filled in for you. When you upgrade from 2.0.56, an empty URL picks up the default automatically. If you already use the hosted service, your existing login carries over.

You can edit the masked URL in **Settings → Connected Account** to use a self-hosted service. Your custom URL persists across updates. Clear the field and leave it to follow the extension’s default again. If a later update moves the default service, select **Connect** to sign in at the new address.
